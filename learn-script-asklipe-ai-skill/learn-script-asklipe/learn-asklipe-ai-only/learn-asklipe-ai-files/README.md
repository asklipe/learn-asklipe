# Arquivos de IA — Learn Script

Este pacote contém somente as instruções e arquivos auxiliares para integrar assistentes de IA à trilha Learn Script.

Comece por `AI-SETUP.md`. O contrato principal do tutor está em `AI-ASSISTANT.md`.

**Importante:** estes arquivos orientam o comportamento do assistente, mas não autenticam contas nem conectam o GitHub automaticamente. A conexão e as permissões precisam ser autorizadas na plataforma de IA utilizada.
