## Como organizar

```text
study/notes/
├── 02-python/
│   ├── mundo-1-aula-01.md
│   └── mundo-1-aula-02.md
└── _TEMPLATE.md
```

Copie o [`_TEMPLATE.md`](_TEMPLATE.md) para a pasta do módulo e preencha depois de assistir. A IA pode sugerir um rascunho, mas você confirma o que é verdade. Nota escrita por você ajuda mais a fixar o conteúdo do que nota gerada pela IA.
