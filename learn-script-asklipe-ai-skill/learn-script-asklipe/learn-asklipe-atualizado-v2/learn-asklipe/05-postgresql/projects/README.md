### Sistema CRUD com PostgreSQL

**Nível:** Intermediário

**🎯 Objetivo:** Aplicar SQL real em um sistema Python: modelagem, criação de tabelas e operações CRUD.

**🧰 Tecnologias:**
- Python 3
- PostgreSQL
- Driver PostgreSQL para Python (ex.: psycopg)

**📋 Requisitos:**
- Modelar ao menos 2 tabelas relacionadas.
- Script SQL de criação do schema.
- CRUD completo via Python.
- Uso de consultas parametrizadas (nunca concatenar strings SQL).
- Credenciais fora do código (variáveis de ambiente).

**🪜 Etapas de desenvolvimento:**
1. Modelar o diagrama de entidades.
2. Instalar e configurar o PostgreSQL.
3. Criar schema e dados de exemplo.
4. Implementar a camada de acesso a dados.
5. Criar a interface de terminal.
6. Documentar como rodar.

**✅ Critérios de conclusão:**
- CRUD funcional nas duas tabelas.
- Nenhuma credencial no repositório.
- Consultas parametrizadas.
- Scripts SQL versionados.
