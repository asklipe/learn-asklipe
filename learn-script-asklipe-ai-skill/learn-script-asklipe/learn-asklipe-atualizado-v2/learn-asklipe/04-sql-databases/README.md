## 🎯 Objetivos de aprendizagem

- Entender o que é um banco de dados relacional.
- Escrever consultas e comandos de manipulação de dados.
- Modelar dados e representar relacionamentos.

## 📋 Conteúdo

- Fundamentos de SQL
- `SELECT`
- `INSERT`
- `UPDATE`
- `DELETE`
- `JOIN`
- Relacionamentos (1:1, 1:N, N:N)
- Modelagem de dados
