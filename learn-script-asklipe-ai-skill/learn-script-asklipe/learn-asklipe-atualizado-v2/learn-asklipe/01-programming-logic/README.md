## 🎯 Objetivos de aprendizagem

- Entender o que é um algoritmo e como decompor problemas.
- Representar soluções em pseudocódigo/fluxograma.
- Dominar variáveis, entrada/saída, condições e repetições (conceitos), antes de escrever Python.
