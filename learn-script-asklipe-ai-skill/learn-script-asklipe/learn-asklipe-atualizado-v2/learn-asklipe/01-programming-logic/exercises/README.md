> Exercícios de prática **propostos por mim** (não são do curso). Resolva primeiro em pseudocódigo/fluxograma; depois, quando chegar ao Python, reimplemente.

## Nível 1 — Entrada, saída e operadores

- Ler dois números e mostrar a soma, a diferença e o produto.
- Ler o raio de um círculo e calcular a área.
- Converter graus Celsius para Fahrenheit.

## Nível 2 — Condições

- Informar se um número é par ou ímpar.
- Ler três notas, calcular a média e informar aprovado/reprovado.
- Dados três lados, dizer se formam um triângulo.

## Nível 3 — Repetições

- Mostrar a tabuada de um número.
- Somar os números de 1 a N.
- Contar quantos números de uma lista são positivos.

## Nível 4 — Problemas combinados

- Jogo de adivinhar um número com dicas "maior/menor".
- Caixa eletrônico: informar quais cédulas compõem um valor.

## Como registrar

Crie um arquivo por exercício (ex.: `n1-soma.md`) com o enunciado, o pseudocódigo e o que você aprendeu.
