> Exercícios **propostos por mim** (não são do curso). Use qualquer SGBD relacional ou o PostgreSQL já instalado no próximo módulo.

## Cenário sugerido: Biblioteca

Tabelas: `autores`, `livros`, `membros`, `emprestimos`.

## Parte 1 — Manipulação

- [ ] Criar as 4 tabelas com chaves primárias.
- [ ] Inserir ao menos 5 registros em cada.
- [ ] Atualizar o e-mail de um membro.
- [ ] Remover um empréstimo devolvido.

## Parte 2 — Consultas

- [ ] Listar livros ordenados por título.
- [ ] Listar livros publicados após determinado ano.
- [ ] Contar livros por autor.

## Parte 3 — Relacionamentos

- [ ] `JOIN` entre livros e autores.
- [ ] Listar empréstimos com nome do membro e título do livro.
- [ ] Listar membros que nunca fizeram empréstimo.

## Parte 4 — Modelagem

- [ ] Desenhar o diagrama entidade-relacionamento.
- [ ] Justificar cada chave estrangeira.
