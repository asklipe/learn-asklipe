## Objetivos de aprendizagem

- Versionar código com Git e publicá-lo no GitHub.
- Trabalhar com branches, merge e pull requests.
- Manter este próprio repositório de estudos organizado.

## Tópicos-alvo

> Lista organizada por mim; confira com a grade do curso.

- O que é versionamento
- Instalação e configuração do Git
- `init`, `add`, `commit`
- Histórico e `log`
- Branches e `merge`
- Repositórios remotos: `push` e `pull`
- Pull requests
- Resolução de conflitos
- `.gitignore`
- Desfazer alterações com segurança
